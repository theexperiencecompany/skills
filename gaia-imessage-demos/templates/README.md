# Template

`props.example.json` is a ten-beat shape, not a finished demo. It shows how an image, a chained greeting, a link card, and a tapback are wired.

Copy it, then replace every line with your own. A full demo is 45 to 55 beats across four to six days.

The readable script is the source of truth. The JSON is a translation. If they disagree, fix the JSON.
